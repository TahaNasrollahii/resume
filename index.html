A backend built on making things reliable. بک‌اندی بنا شده روی قابل‌اعتماد بودن.

I design REST APIs, background workers and data models that hold up under real traffic — not just in a demo. Lately that means Celery pipelines split across dedicated queues, WebSocket layers that replace polling, and LLM features that fail gracefully when the model doesn't. Outside of client work, I run Titan Item, a small digital services brand. من روی API های REST، ورکرهای پس‌زمینه و مدل‌های داده‌ای کار می‌کنم که زیر بار واقعی هم پایدار بمانند، نه فقط در دمو. این روزها یعنی پایپ‌لاین‌های سلری تقسیم‌شده روی صف‌های اختصاصی، لایه‌های WebSocket به‌جای polling، و قابلیت‌های مبتنی بر LLM که در صورت خطای مدل هم درست مدیریت می‌شوند. جدا از پروژه‌های مشتری، برند خدمات دیجیتال کوچکی به نام Titan Item را هم اداره می‌کنم.
