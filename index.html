A bit about meکمی درباره من

My path started with a love for computers, which I've pursued through a Computer Engineering degree. To build a solid backend foundation, I completed the Python & Django Bootcamp at Kelaasor, then stayed on to help build the platform itself. Alongside that I run Titan Item, a small digital services brand. Today I focus on async architecture, real-time systems, and APIs that hold up under real traffic. علاقه من به کامپیوتر از همان ابتدا شکل گرفت و آن را در قالب کارشناسی مهندسی کامپیوتر دنبال کردم. برای پایه‌ریزی یک بک‌اند محکم، بوت‌کمپ پایتون و جنگو کلاسور را گذراندم و بعد از آن در توسعه خود پلتفرم هم مشارکت کردم. در کنار این‌ها، برند خدمات دیجیتال کوچکی به نام Titan Item را هم اداره می‌کنم. امروز تمرکزم روی معماری ناهم‌زمان، سیستم‌های real-time و API هایی است که زیر بار واقعی هم پایدار می‌مانند.
